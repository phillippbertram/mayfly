# Website review captures

These captures show the actual locally exported FileHop website, reviewed on
2026-11-02 with the `/filehop` GitHub Pages project path.

- `website-desktop.jpg`: desktop product-page viewport.
- `website-full.jpg`: the complete desktop product page.
- `website-manual.jpg`: the English Fumadocs manual.
- `website-mobile.jpg`: the product page at a 390-pixel mobile viewport.
- `website-features.jpg`: the new screenshot tour and its selectable feature descriptions.

Application screenshots used by the site are separately documented in
`apps/website/public/screenshots/README.md`. They show the real browser-preview
interface with sample data, not completed native transfers. The product page and
manual describe the current native development build, including local sharing,
editable multiple-file links, ZIP downloads, saved settings, and link profiles.
The tour animates actual screenshots and is not a transfer recording. Nothing in these
captures establishes a publicly deployed website or released installer.
