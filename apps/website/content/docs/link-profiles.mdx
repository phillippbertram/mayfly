## Browser first

Two built-in profiles are always available:

- **Download page** opens a page that shows the files and their download buttons.
  It's the default and the safest choice: opening the page never counts as a download.
- **Direct download** starts the download right away. For several files shared with
  one link, it downloads them as one ZIP. Chat apps that show link previews fetch
  the link first, which can use up a download when a limit is set.

Choose the profile when you share, or later in the share details. Custom profiles describe how a compatible application expects to receive a file URL.
They do not install an application, register a scheme, or create network connectivity.

## Create a profile

In the interface preview, open **Settings → Link profiles**, choose **New profile**,
and enter a name and template. For example:

```text
Name: My import app
Template: myapp://import?url={encodedUrl}&name={encodedFilename}
```

`myapp` is an example scheme, not a claim about an installed application. Use the
scheme and import format documented by your actual target app.

## Available placeholders

| Placeholder | Value |
| --- | --- |
| `{url}` | Full mobile download-page URL |
| `{encodedUrl}` | That URL encoded as a single URI component |
| `{filename}` | Original filename |
| `{encodedFilename}` | Filename encoded as a single URI component |
| `{token}` | Share token |

Prefer encoded values inside query parameters. Templates are resolved once:
braces in inserted filenames must not become a second round of placeholders.
Unknown placeholders and executable schemes are rejected by the intended backend.

## Select a default or switch per share

The interface lets you mark a default profile and choose a different one in the
share inspector. Deleting the default should fall back to HTTP. Profile persistence
and actual deep-link handoffs still need Rust implementation and compatible-device tests.

A custom profile does not turn a local address into a public one.
See [Remote sharing](../remote-sharing/) for that separate topic.
