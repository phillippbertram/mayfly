## What you can use today

The native desktop development build includes real local file sharing, a browser
download page, ZIP downloads, QR actions, saved settings and profiles, and tray
behavior. There are no public stable installers yet. Packaged-platform, phone,
and second-device acceptance are still pending; implemented features are not a
claim that all operating systems and devices have been verified.

For installer availability, use the website's [Downloads](../../#download) section.
Apple Silicon and Intel on macOS, Windows x64, and Linux package choices remain
visible. Minimum OS versions will accompany verified release assets.

## Install a test package

<Callout title="No verified publisher signature yet" type="warn">
macOS packages use ad-hoc signing without Apple Developer ID signing or notarization.
Windows installers are unsigned. Expect operating-system warnings, and continue
only for an official Mayfly download whose source and checksum you have verified.
Platform/device acceptance remains pending.
</Callout>

Download the package for your system from [Downloads](../../#download) or its
linked release. Compare its SHA-256 with the exact asset's `SHA256SUMS` entry
before opening it. On macOS, use `shasum -a 256` with the downloaded file; on Linux,
use `sha256sum`; on Windows, use PowerShell's `Get-FileHash -Algorithm SHA256`.
A matching hash detects corruption and does not verify the publisher's identity.

### macOS: allow this app's first launch

1. Choose Apple Silicon or Intel to match your Mac, open the `.dmg`, and drag
   **Mayfly.app** into **Applications**. Eject the disk image.
2. Try opening Mayfly from Applications once. Dismiss the warning that its
   developer cannot be verified or Apple cannot check the app.
3. Open **System Settings → Privacy & Security**, scroll to Security, and select
   **Open Anyway** beside the message about Mayfly.
4. Confirm **Open**, and authenticate if asked. This grants an exception to this
   app; future launches normally use the usual shortcut.

Older macOS versions use **System Preferences → Security & Privacy → General**.
If the button is absent, try opening the installed app again first. Managed Macs
may prevent exceptions. See [Apple's first-launch instructions](https://support.apple.com/en-us/102445).

An alert that an app **will damage your computer** or **is damaged** is different
from the expected unidentified-developer prompt. Stop, check the download again,
and report a reproducible failure. Keep Gatekeeper and quarantine protections
enabled rather than using a global bypass or stripping file attributes.

### Windows: unsigned installer

Open the Windows x64 `.exe` after verifying its checksum. If SmartScreen displays
**Windows protected your PC**, choose **More info → Run anyway**, when offered
and you trust the verified download. The permission prompt may show **Unknown
publisher**. Complete the installer and launch Mayfly from the Start menu.

Smart App Control or an organization's policy may block unsigned programs without
offering that exception. Keep the protection enabled and request an approved build
or build from source. Do not override a malware detection. Microsoft's
[distribution guide](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/publish-first-app)
explains the first-run trust limitations.

### Linux: package or AppImage

Choose the `.deb` for a supported Debian/Ubuntu system, or an AppImage for a
compatible distribution. Verify the checksum, then use the distribution's package
installer for the `.deb`. For an AppImage, use its file properties to allow
execution and open it. FUSE, WebKitGTK, and tray requirements vary by distribution;
an AppImage does not guarantee compatibility everywhere.

The release also includes `INSTALLATION.md` with the complete platform steps and
the [license and third-party notices](../licenses/). These instructions describe
the prepared packages; they do not claim that public installers already exist.

## Run from source

You need Node.js 24, pnpm 11.15.1, Rust through rustup, and the
[Tauri prerequisites](https://v2.tauri.app/start/prerequisites/) for your operating
system. Clone the source repository when available, or use an authorized local checkout.

From the repository root:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

On macOS/Linux, if `cargo` is not on PATH after installing Rust:

```sh
. "$HOME/.cargo/env"
pnpm dev
```

The first native build downloads and compiles dependencies. Allow a few minutes.
The native app starts its local sharing server and displays its network status.

## Your first local share

1. Connect the computer and receiving device to the same reachable, trusted network.
2. Confirm that Mayfly shows a usable network address. Choose another under
   **Settings → Network** if needed.
3. Choose or drop files, set a lifetime and optional download limit, and select **Share**.
4. Scan the share's QR code or copy its link to the receiving browser.
5. Download individual files or choose **Download all** for a ZIP.

Keep the computer awake and Mayfly running. Local HTTP is unencrypted; no router
port forwarding is needed. See [Share files](../sharing/) for changing a link's
contents, creating empty links, and naming a share.

## Explore without Rust

```sh
pnpm dev:web
```

Open `http://127.0.0.1:1420`. This separate preview uses clearly labeled sample data
and serves no files. It lets you explore the share list, QR inspector, settings,
and profiles without starting Rust. It does not verify native behavior.
