## Open the share inspector

Select a share or use **Show QR code**. The interface presents a large code, the
share's files, the share link, and copy/save actions.
The browser preview renders real QR images from sample URLs; the URLs do not serve files.

## Scan from an iPhone

Open Camera, point it at the complete code, and tap the detected link. The default
code opens a browser page listing the share's files, with individual downloads and
**Download all** for a ZIP. No companion app is required for this default workflow.
Phone and second-device acceptance are still pending.

Keep the whole QR code visible, including the clear border around it. If scanning
fails, enlarge the inspector, improve screen brightness, or use the copied link.

## Copy or save

- **Copy link** in the inspector copies the displayed QR target. The row's copy
  action always copies the share-page link.
- **Copy QR image** copies an image rather than a text URL.
- **Save QR as PNG** opens your system's save dialog and writes the code as an image file.

If another device can't open the link, open **Can't open the link on another device?**
under the QR code in the share details for the usual causes: different networks, guest
Wi-Fi or client isolation, a VPN, or the firewall. See also [Troubleshooting](../troubleshooting/).

In the browser-only preview, these actions use the browser's own clipboard and download,
not the desktop app's.

## A QR code for one file or an app

Select the QR button next to a file to show its direct-download code. **Show share
QR** returns to the share's QR target. Direct downloads count against the file's
limit, including requests made by scanners or link previews.

With a custom [link profile](../link-profiles/), **What the QR code opens** lets you
choose a compatible app instead of the share page. The displayed link, copied QR
image, and saved PNG follow the selected target. Custom schemes require that app
on the receiving device; a profile does not make your network reachable.

## A QR code is a credential

The code contains the share URL, including its access token. Anyone who obtains it
and can reach the server can use the share while it remains available.
Do not post a screenshot of a real active code in a public issue.

Changing the selected IP, port, or external hostname requires an updated link and
QR code. An old image cannot update itself. Adding or removing files or changing
the share's title preserves the share-page link and its QR code.
