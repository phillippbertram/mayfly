FileHop is being built for one small, everyday moment: you have a file on your
computer, and you want it on your phone. The intended workflow is simple: choose
a file, scan its QR code, and download it in your phone's browser.

<Callout title="Development preview" type="info">
The desktop interface is implemented. The Rust file-sharing server, real transfers,
and public installers are still in development. Screenshots with sample files show
the actual browser-preview interface, not a completed file transfer.
</Callout>

## How this manual works

Pages distinguish the current interface preview from planned sharing behavior.
You can explore the interface today; instructions for real transfers become
actionable when the backend and a verified release are available.

FileHop's default design requires no account, mobile companion app, or cloud relay.
Optional remote-access tools introduce their own accounts, apps, and trust boundaries.

## Current availability

There is no public stable installer yet. Visit [Downloads](../#download) for
release availability. Do not treat a screenshot's example address or QR code as a
live share. Never use FileHop's development server to distribute files.
