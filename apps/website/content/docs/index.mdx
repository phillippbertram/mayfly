FileHop shares files from your desktop to a browser on your local network. Choose
one file or a few, scan the QR code, and download. No account, cloud upload, or
companion mobile app is required for local sharing.

<Callout title="Development build" type="info">
Real local sharing is implemented in the desktop development build. Public installers
and phone, second-device, and packaged-platform acceptance are still pending.
Website screenshots show the actual browser-preview interface with sample data;
they are not recordings of real transfers.
</Callout>

## A link that can change with you

Share several files behind one link, give it a title, and add or remove files later.
You can also create an empty link before choosing files. Recipients refresh the
page to see changes, then download individual files or everything as a ZIP.
Everyone with the link can access files you add later; use separate links for
different audiences.

Settings and custom link profiles are saved locally. Active shares and tokens stay
in memory and become invalid after a full app restart.

## Current availability

There is no public stable installer yet. Visit [Downloads](../#download) for
release availability. An authorized source checkout can run the native app;
`pnpm dev:web` is a sample-data interface simulator with no working downloads.

Use a trusted network: local HTTP is unencrypted. Optional remote-access tools
introduce their own connectivity and trust boundaries and remain unverified.
Do not treat a screenshot's example address or QR code as a live share.
