title: Troubleshooting
description: Find the missing connection, one small check at a time.
---

## macOS or Windows blocks the downloaded app

Current macOS test packages are ad-hoc signed without notarization; Windows
installers are unsigned. Follow the [first-launch instructions](../getting-started/#install-a-test-package)
to verify the download and, when offered, approve this app through macOS
**Privacy & Security → Open Anyway** or Windows SmartScreen's **More info → Run anyway**.
Malware/damaged-app alerts and managed-device policy blocks are different from an
unrecognized-publisher warning. Do not disable system protections to bypass them.

## The app is offline or cannot start its server

Check the server status in the header and open **Settings → Network**. Select an
address the receiving device can reach. If port 8765 is occupied, choose an unused
port; share links and QR codes need the current address and port. A failed port
change keeps the last usable listener.

The browser-only preview (`pnpm dev:web`) is a simulator. Its online badge and
sample QR codes never provide working downloads. Use the native app (`pnpm dev`)
for real sharing.

## The QR opens a link, but my phone cannot connect

1. Check that both devices can reach each other on the same trusted network.
2. Keep the desktop awake and Mayfly running, with a usable address in its header.
3. Select the Wi-Fi/interface address reachable from the phone.
4. Check that guest Wi-Fi or router client isolation is not separating the devices.
5. Allow Mayfly through the desktop firewall on the intended private network.

A VPN may change routing or the advertised interface. Re-select the correct address
and scan the updated code. Do not disable the firewall globally or forward the port
to the internet to fix local sharing. Phone and second-device acceptance are still
pending; include your device and network details when reporting a problem.

## The camera will not recognize the QR

Show the entire code and its clear border, increase display brightness, and hold
the phone steadily. Copy the link as an alternative. If using an app profile,
check **What the QR code opens** and verify that the compatible app is installed.
Choose **Share page** to use a browser instead.

## The page says “No files yet”

The owner may have created an empty link or removed its files. Refresh after they
add files. The share's original lifetime still applies while it is empty.

## A download expires or reaches its limit

Ask the owner for a new share. Expired and revoked URLs do not become valid again.
A limit applies per file and counts when a download starts. Link previews, scanners,
retries, and interrupted downloads can use an allowance; opening the share page
does not. Prefer the share-page link when sending a limited share in chat.

## A file is unavailable or a large transfer stops

Keep the computer awake and connected. Mayfly streams the original contents; if
a file's size changes, it reports the file as unavailable. Removing a file, stopping
a share, or fully quitting Mayfly cancels running transfers. Expiration prevents
new downloads but lets already-started downloads finish.

Check free space on the receiving device. A retry starts the full file again;
partial-download resume is not supported. Optional remote proxies have separate
limits and timeouts and are not a verified Mayfly workflow.

## Closing the window did not stop sharing

Closing normally hides Mayfly in the menu bar or tray. Use **Stop sharing** to end
one link, or **Quit Mayfly** to stop all shares and downloads. On Linux without
AppIndicator support, closing quits instead. See [Settings](../settings/).

## The development server cannot start

Port 1420 may already be used by another desktop preview. Stop the preview you own
before starting `pnpm dev`; do not terminate unrelated processes. Check Node/pnpm
versions and load Rust's environment if `cargo` is not found.

## Report a reproducible problem

Include the Mayfly version/commit, OS and architecture, browser/device, sanitized
steps, expected result, and observed result. State whether you used the native app
or sample-data browser preview. Remove tokens, private filenames, and local paths.
