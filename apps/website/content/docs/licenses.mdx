## Third-party source code

Every listed component includes a link to its published source distribution.
For MPL-2.0 components, those links provide the corresponding Source Code Form.
Mayfly does not edit those third-party source files. Some build dependencies and
crates for other target platforms are included for completeness; a listing does
not mean every component is present in a particular installer or in browser code.

## Installed copies

Installers include the three files in the app's `licenses/` resource directory.
On macOS, choose **Show Package Contents** on Mayfly.app, then open
**Contents → Resources → licenses**. On Windows, open `licenses` beside the
installed executable. On Linux, look in the application's resource directory
under `usr/lib`, including inside the AppImage's `usr/lib` tree.

The same documents accompany release assets for review before installation.
Platform libraries and installer-added components are reviewed against each actual
bundle before public distribution; see the repository's
[licensing process](https://github.com/phillippbertram/mayfly/blob/main/docs/licensing.md).
