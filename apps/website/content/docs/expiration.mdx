## Lifetime options

The share options offer **5 minutes**, **10 minutes** (default), **30 minutes**,
**1 hour**, **Until stopped**, and a **Custom** lifetime. The Rust backend enforces expiration on every
request; the interface's countdown is informational.

Until stopped means no scheduled deadline. It does not mean a permanent link:
revocation, full application exit, or a restart will invalidate the in-memory share.

## Download limits

An optional positive download limit applies to each file. Once every file has used
its allowance, the share reaches its limit. A download counts when it starts, so a count of one is not proof that the
recipient saved the file successfully.

- Opening the share page and `HEAD` requests never count.
- A download that is interrupted or canceled still counts; retrying is a new download.
- Resuming a partial download isn't supported; the browser receives the whole file again.
- If Mayfly can't read the file, the attempt doesn't count.
- With one link for several files, the limit applies to each file. **Download all**
  uses one download of every file and is offered only while each file has one left.

Simultaneous requests can never exceed the limit. The browser preview's counters
demonstrate the interface only.

## Stop sharing early

Use **Stop sharing** in share details or the share's action menu. New page and
download requests are refused immediately, and downloads already running are cut
off. When a share expires instead, downloads that already started may finish.

## How a share’s life shows

In the list, a share is **Live** while it can be downloaded and **Fading** in its
last two minutes. Once its time runs out it is **Gone**. **Stopped** and **Limit
reached** keep their plain names, because they describe a decision, not the clock.

Gone and stopped shares may remain in the list for clarity. Sharing again
creates a fresh share and token; it does not reactivate the old URL.

## Start over safely

Settings and link profiles persist; active shares and tokens are not stored.
After a full restart, recipients need fresh links. Closing the window keeps sharing
in the background; quitting stops every share.
